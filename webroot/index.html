导入说明
兼容 20 段增益 JSON / 自定义曲线

      

      

        
{
  "format": "com.weich.daptune.profile",
  "band_plan": "dolby-dap-20-v1",
  "frequencies_hz": [47, 141, ...],
  "gains_q4": [320, 299, ...]
}

        
    
          
  • gains_q4 / gains / bands[].gain 均可识别，自动取 20 段。
    • 
          
  • 数值单位为 0.01 dB（与 Dolby target / gain 一致），320 = +3.20 dB。
    • 
          
  • 频点必须与 dolby-dap-20-v1 计划一致，导入时会校验。
    •
